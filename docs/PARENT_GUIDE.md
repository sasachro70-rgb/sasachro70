# คู่มือผู้ปกครอง · Parent Dashboard guide

(English summary at the end.)

## 1. เข้าหน้าผู้ปกครอง

1. เปิด `parent.html` (หรือกด **ผู้ปกครอง** ที่หน้าแรกของ Family Game Hub)
2. ครั้งแรก: ตั้งรหัส **PIN ผู้ปกครอง** (ตัวเลข 4–8 หลัก) อย่าให้เด็กรู้
3. ครั้งต่อไป: ใส่ PIN ใส่ผิด 5 ครั้งจะถูกล็อก 1 นาที (ผิดอีก 5 ครั้ง ล็อก 5 นาที)
4. หน้าผู้ปกครองล็อกเองเมื่อไม่ได้ใช้ 15 นาที หรือกด **ล็อก**

ลืม PIN: ถ้าใช้บัญชีครอบครัว เจ้าของครอบครัวล้าง PIN ได้ (ฟังก์ชัน `reset_parent_pin`) ถ้าใช้แบบเครื่องเดียว ต้องล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ (ควรดาวน์โหลดไฟล์สำรองไว้ก่อน: ตั้งค่า → ดาวน์โหลดไฟล์สำรอง)

## 2. แท็บต่าง ๆ

| แท็บ | ใช้ทำอะไร |
|---|---|
| ภาพรวม | คะแนนคงเหลือ ได้รับ ใช้ไป รออนุมัติ นาทีและคะแนนในสัปดาห์นี้ กราฟ 7 วันของเด็กแต่ละคน และสรุปผู้เรียนผู้ใหญ่ |
| คำขอ | คำขอแลกรางวัลที่รออยู่ → **อนุมัติ** (หักคะแนน) หรือ **ปฏิเสธ** (ไม่หักคะแนน ใส่ข้อความถึงเด็กได้) |
| รางวัล | สร้าง แก้ไข ลบรางวัล (ดูข้อ 3) |
| คะแนน | ประวัติคะแนนทุกรายการพร้อมยอดคงเหลือ และ **ปรับคะแนน** (+/−) พร้อมเหตุผล |
| ประวัติ | กิจกรรมทั้งหมด: เกม บทเรียน KeyKids เกมครอบครัว เวลา และผล กรองตามคนหรือส่วนได้ |
| การเรียน | บทเรียนภาษาที่เรียนจบ / เริ่มแล้วแต่ยังไม่จบ / ยังไม่เริ่ม คำศัพท์ที่ยังไม่แม่น และความก้าวหน้าของผู้ใหญ่ (A1–C1) |
| โปรไฟล์ | เพิ่ม แก้ไข ลบโปรไฟล์ เด็ก/ผู้ใหญ่ อายุ ระดับความยาก (ตามอายุ หรือกำหนดเอง) เป้าหมายนาทีต่อวัน |
| ตั้งค่า | กติกาคะแนน คำศัพท์ของครอบครัว เปิด/ปิดบทเรียน บัญชีครอบครัว เปลี่ยน PIN ไฟล์สำรอง |

ลบโปรไฟล์: โปรไฟล์จะหายจากทุกรายการ แต่ประวัติคะแนนยังเก็บไว้ ข้อมูลใน KeyKids และฮับไม่ถูกลบ

## 3. คู่มือการเพิ่มรางวัล

1. ตั้งค่า → แท็บ **รางวัล** → **รางวัลใหม่**
2. กรอก:
   * **ชื่อรางวัล** เช่น “เลือกขนมที่ชอบ” และ **ไอคอน** (อีโมจิ) หรือ **รูปภาพ** (ย่อให้เล็กอัตโนมัติ)
   * **รายละเอียด** (ไม่บังคับ)
   * **คะแนนที่ต้องใช้** เช่น 50
   * **แลกได้กี่ครั้งต่อเด็ก** และ **จำนวนทั้งหมด** (เว้นว่าง = ไม่จำกัด)
   * **เริ่มแลกได้ / หมดอายุ** (ไม่บังคับ)
   * **เปิดใช้งาน** และ **อนุมัติอัตโนมัติ** (ถ้าเลือก จะหักคะแนนทันทีโดยไม่ต้องรอผู้ปกครอง)
   * **สำหรับ**: เลือกเด็กบางคน หรือไม่เลือก = เด็กทุกคน
3. กด **บันทึก**

ตัวอย่างที่แนะนำ:

| คะแนน | รางวัล |
|---|---|
| 50 | เลือกขนมที่ชอบ |
| 100 | เล่นเกมเพิ่ม 30 นาที |
| 200 | เลือกกิจกรรมกับครอบครัว |
| 500 | ของเล่นใหม่ |
| 1,000 | รางวัลพิเศษ |

ลบรางวัลที่เคยมีคนแลกแล้ว: ระบบจะ “เก็บเข้าคลัง” แทนการลบ เพื่อให้ประวัติยังอ่านได้ ถ้ามีคำขอรอค้าง ต้องตัดสินใจก่อน

## 4. การแลกรางวัลทำงานอย่างไร

1. เด็กเปิด **แลกรางวัล** ใน `kids.html` เห็นรางวัล คะแนนที่ต้องใช้ และคะแนนที่มี
2. กด **แลก** → ยืนยัน → คำขอส่งถึงผู้ปกครอง คะแนนถูก **จองไว้** แต่ยังไม่หัก
3. ผู้ปกครองอนุมัติ → หักคะแนนครั้งเดียว / ปฏิเสธ → ไม่หักคะแนน
4. ระบบป้องกัน: ขอรางวัลเดิมซ้ำขณะรออยู่ไม่ได้ คะแนนที่จองไว้ใช้ซ้ำไม่ได้ คะแนนติดลบไม่ได้ อนุมัติซ้ำไม่ได้

## 5. กติกาคะแนน (ค่าเริ่มต้น เปลี่ยนได้ที่ ตั้งค่า)

| กิจกรรม | คะแนน |
|---|---|
| บทฝึกพิมพ์ KeyKids (ได้อย่างน้อย 1 ดาว) | 10 |
| เกมสะกดคำ / ธงชาติใน KeyKids | คะแนนเกม สูงสุด 100 |
| เกมความรู้ / เกมครอบครัว | ข้อที่ถูก × 2 × ระดับ (1–4) |
| จบบทเรียนภาษา | 20 + โบนัส 10 ถ้าได้ 80 % ขึ้นไป |
| ทบทวนคำศัพท์ | 1 ต่อคำที่ถูก สูงสุด 20 |
| ทำครบเป้าหมายนาทีต่อวัน | โบนัส 15 (วันละครั้ง) |
| เล่นซ้ำสิ่งที่เคยจบแล้ว | ได้ 50 % |
| เพดาน | 150 ต่อกิจกรรม, 400 ต่อเด็กต่อวัน |

ผู้ใหญ่ไม่ได้รับคะแนนแลกรางวัลเด็ก แต่มีความก้าวหน้าและสถิติของตัวเองใน Adult Language Academy

## 6. ใช้หลายเครื่อง (บัญชีครอบครัว)

ดู `docs/DEPLOY.md` ข้อ 3 เมื่อเชื่อมแล้ว: ตั้งค่า → **อัปโหลดข้อมูลในเครื่องนี้ขึ้นบัญชีครอบครัว** (ครั้งเดียว) จากนั้นทุกเครื่องที่เข้าสู่ระบบด้วยบัญชีของครอบครัวจะเห็นคะแนน รางวัล และความก้าวหน้าเดียวกัน

### English summary

Open `parent.html`, set a 4–8 digit parent PIN, then use the tabs: **Overview** (balances, week charts), **Requests**
(approve = points spent once, reject = nothing spent), **Rewards** (name, icon or picture, description, cost, per-child
and total limits, start/end dates, active, auto-approve, which children), **Points** (full history, adjust with a reason),
**History**, **Learning**, **Profiles** (child/adult, age, difficulty override, daily goal) and **Settings** (points rules,
family words, lessons on/off, family account, change PIN, backup). Removing a profile keeps its points history.
